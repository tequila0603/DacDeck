# DacDeck

Tray app for Windows that controls the EQ of FiiO / SNOWSKY USB DACs, starting with the **SNOWSKY Melody**,
without the FiiO Control web page.

- Tray icon with a quick menu: EQ preset (Jazz, Pop, Rock, Dance, R&B, Classic, Hip-hop, USER1–3, off) and EQ global gain, with a popup on every change.
- EQ window: response graph with draggable band handles (drag = frequency / gain, mouse wheel = Q), all 10 bands (type, frequency, gain, Q), EQ global gain.
- Edits play live; **Save** stores them in the DAC's USER slot.
- Factory presets are read-only; copy one into a USER slot to edit it.
- AutoEq / Squiglink import (`ParametricEQ.txt`): fitted to 10 bands and the device limits, saved into a USER slot.
- Starts with Windows (optional), finds the DAC when it is plugged in.
- Hardware output gain (Low / High): not supported yet. Its USB command is not documented for the Melody.

## Build

Windows 10/11 with the .NET Framework 4.x that ships with Windows (no SDK needed):

```powershell
powershell -ExecutionPolicy Bypass -File .\build.ps1
.\DacDeck.exe --check     # self-check
.\DacDeck.exe --probe     # read-only: lists the DAC's HID interfaces, reads firmware, preset, gain and bands
.\DacDeck.exe             # tray icon + EQ window (--minimized: tray only)
```

Close the FiiO Control web page while DacDeck runs: only one program can talk to the DAC at a time.

## Protocol and credits

The DAC is driven over USB HID with FiiO's shared command set. The protocol comes from
[fiioctl](https://github.com/ethanbarclay/fiioctl) (MIT), whose authors verified it on a FiiO KA15. The Melody's presets
and USER slots come from [devicePEQ](https://github.com/jeromeof/devicePEQ) (0BSD). Neither project has verified it on a
Melody, so DacDeck reads back every value it writes and reports any value the DAC did not take.

Logs: `%LOCALAPPDATA%\DacDeck\DacDeck.log`. The icon is generated by `tools/make_icon.py` (Pillow).

DacDeck is not affiliated with FiiO or SNOWSKY.
